# Contribute and report

## Where does the issue belong?

| Concerns | Open the issue in |
| --- | --- |
| Bastion for Apple | [New issue](https://github.com/Myrpisset/bastion-apple/issues/new/choose) |
| Bastion for Linux | [New issue](https://github.com/Myrpisset/bastion-linux/issues/new/choose) |
| Bastion for Windows | [New issue](https://github.com/Myrpisset/bastion-windows/issues/new/choose) |
| Bastion for Android | [New issue](https://github.com/Myrpisset/bastion-android/issues/new/choose) |
| Every platform, the sync format or this site | [Bastion](https://github.com/Myrpisset/bastion/issues/new/choose) |

If you are unsure, open it here. It will be moved to the right repo.

## Projects

The organization's [projects](https://github.com/orgs/Myrpisset/projects) track work across the five repos.

## Security problems

Never report a vulnerability in a public issue. Follow [SECURITY.md](https://github.com/Myrpisset/bastion/blob/main/SECURITY.md) and use private vulnerability reporting in the affected repo.

## Contributing code

Code changes go into the platform's repo, not here. Each repo has a `CONTRIBUTING.md` and an `AGENTS.md` with commands and rules. The rules for every repo are in [GOVERNANCE.md](https://github.com/Myrpisset/.github/blob/main/GOVERNANCE.md).
